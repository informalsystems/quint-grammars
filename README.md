# quint-tmlanguage

TextMate grammar for the [Quint](https://quint-lang.org) specification language.

This repository is the canonical source for syntax-highlighting support for
Quint and is intended to be consumed by:

- [GitHub Linguist](https://github.com/github-linguist/linguist), to provide
  syntax highlighting on GitHub for `.qnt` files.
