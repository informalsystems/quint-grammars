# quint-grammars

Syntax-highlighting grammars for the [Quint](https://quint-lang.org)
specification language.

This repository is the canonical source for syntax-highlighting support for
Quint. Each subdirectory holds a grammar in a different format. Today it
contains a TextMate grammar; other formats may be added later.

## Layout

- `textmate/quint.tmLanguage.json` — TextMate grammar
  (scopeName: `source.quint`). Consumed by
  [GitHub Linguist](https://github.com/github-linguist/linguist) for
  syntax highlighting on GitHub.
